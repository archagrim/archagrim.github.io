Ouvrir le Codex

Installer sur iPhone

  1. Ouvre cette page dans Safari.
  2. Touche le bouton Partager (carré avec une flèche vers le haut).
  3. Choisis Sur l'écran d'accueil, puis Ajouter.

Installer sur Android

  1. Ouvre cette page dans Chrome.
  2. Touche Installer l'app ci-dessus, ou le menu ⋮ puis Installer l'application.
  3. Confirme : l'icône Codex apparaît avec tes autres apps.

Installer sur ordinateur

  1. Ouvre cette page dans Chrome ou Edge.
  2. Clique sur l'icône d'installation à droite de la barre d'adresse.
  3. Le Codex s'ouvre ensuite comme une app, depuis le menu Démarrer ou le Dock.

Tes notes restent synchronisées : le Codex s'ouvre sur ton compte Claude. Si Claude te demande de te connecter la première fois, connecte-toi avec ton compte habituel.
